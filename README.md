# 🐍 Python Projects & Logic Archive

A organized monorepo containing various Python applications, Object-Oriented Programming (OOP) architectures, CLI-based interactive modules, graphical user interfaces (GUI), and algorithmic logic challenges.

---

## 🛠 Project Modules Overview

This repository is divided into distinct directories, each serving a specific domain of Python development:

| Module Directory | Key Technologies / Domain | Description |
| :--- | :--- | :--- |
| **`pbo_praktik_cli`** | OOP, CLI, Python | Practical Object-Oriented Programming exercises covering inheritance, encapsulation, and class structuring. |
| **`CLI-Blackjack-Casino`** | Game Logic, CLI, Randomization | Terminal-based Blackjack game featuring full card-dealing mechanics, betting logic, and state management. |
| **`Python-OOP-Hero-System`** | OOP, Entity Architecture | Turn-based RPG hero framework demonstrating class interactions, stat scaling, and ability systems. |
| **`Tkinter-Calculator`** | GUI, `tkinter`, Event Handling | Desktop calculator app with clean layout positioning and dynamic expression evaluation. |
| **`CLI-Calculator-Core`** | Core Math, Parser | Lightweight CLI math solver supporting chained operations and input validation. |
| **`Python-Logic-Sandbox`** | Data Structures, Control Flow | Collection of modular Python scripts experimenting with loops, conditionals, and array manipulations. |
| **`Sudoku-Recursive-Engine`** | Backtracking Algorithm | Automated Sudoku solver built using recursive backtracking algorithms to solve standard 9x9 grids. |
| **`Dynamic-Math-Grid`** | Matrix Logic, Visual Output | Dynamic array and grid-rendering engine for spatial math computations and matrix manipulation. |
| **`Academic-Record-System`** | Data Management, CRUD | System for storing, updating, and computing high school student grades and GPA metrics. |

---

## 🚀 Getting Started & Execution

Each folder operates independently. To run any module, clone the repository, navigate to the target directory, and execute the main script:

```bash
# 1. Clone the repository
git clone [https://github.com/riberii/Python-Projects-Archive.git](https://github.com/riberii/Python-Projects-Archive.git)

# 2. Navigate into your desired project directory
cd Python-Projects-Archive/Sudoku-Recursive-Engine

# 3. Run the application
python main.py
