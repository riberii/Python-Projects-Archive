I maintained this script as a personal playground to test and refine my understanding of Python's core features. Rather than a single focused application, this project is a repository of varied logical challenges, ranging from terminal UI formatting to game mechanics and mathematical loops. It was my primary way of experimenting with how code can solve everyday problems like calculating a restaurant bill or create interactive entertainment, such as a rock paper scissors game or a numeric guessing challenge.

A large portion of these exercises focuses on the aesthetics of terminal output. I experimented heavily with Python's f string alignment and the format() method to create professional looking menus and headers. By manipulating string multiplication and center alignment (^), I practiced building complex visual structures in the console, such as the "Warung Sedap" price list and various geometric shapes like squares and diamonds. This phase of learning taught me how to present data clearly to a user, which is a vital skill for any developer building command line tools.

Many sections of the script, such as the grade average calculator and the pizza price estimator, dive deep into conditional branching. I practiced using if elif else structures to handle multiple variables and user choices simultaneously. To ensure the program was robust, I also implemented basic input validation logic checking if scores fall between 0 and 100 or if a user’s choice matches the expected input. This helped me understand the importance of defensive programming and how to manage the flow of a program based on unpredictable user behavior.

The latter half of the script explores the differences between for loops and while loops. I used these to create countdown timers, automated shape generators, and iterative games. For example, the shape drawing exercises required me to think about how numerical patterns (like adding or subtracting asterisks) translate into visual symmetry on the screen. By integrating the random and time modules, I added layers of complexity such as delays for dramatic effect in games or randomized computer choices giving the terminal a more dynamic and "alive" feeling.

This collection was a vital step in mastering the "building blocks" of programming. It taught me how to combine different modules and logic structures to build larger, more complex systems. If I were to revisit these exercises, I would focus on refactoring the repetitive sections into reusable functions to make the code more "DRY" (Don't Repeat Yourself). I am also interested in moving some of this logic into a graphical interface or a web application to see how these core principles apply to modern software environments.
