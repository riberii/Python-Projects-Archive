I developed this project to practice the core principles of Object Oriented Programming by building a system that manages student academic records. The goal was to move beyond simple variables and instead use a data class to represent a student as a complex object with multiple attributes, such as age, gender, and specific subject grades. By centralizing the logic for adding, searching, and deleting records within the class methods, I created a modular system that is easy to maintain and expand.

The technical foundation of the script is the interaction between the data class and a global list that acts as the database. When a new student is added, the accept method instantiates a new object and appends it to the list. I implemented a robust search algorithm that iterates through this list to find matches based on the student's name, allowing for case insensitive queries. This project also helped me master the use of the self keyword in Python, ensuring that each method correctly references the specific instance of data it needs to display or modify.

One of the most important aspects of this project was ensuring data integrity. I implemented multiple while True loops combined with try except blocks to validate user input. This prevents the program from crashing if a user enters a letter where a number is expected and ensures that grades are always within the valid range of 0 to 100. I also spent time on the interface, using a numbered menu system and clear prompts to make the management process intuitive for the operator. This taught me that the "logic" of a program is only half of the work; the other half is making sure the program can handle "dirty" data from the user without failing.

In the future, I plan to implement the "Update" feature, which would allow a user to change specific details of a student's record without deleting and re entering the whole profile. I am also interested in adding a data persistence layer, such as saving the student list to a CSV or JSON file, so that the information isn't lost when the program is closed. Eventually, I could see this evolving into a full web based dashboard using Flask, where teachers could log in to manage their classes through a graphical interface.
